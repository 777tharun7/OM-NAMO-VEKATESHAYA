# MVP Blueprint — Project Introvert

**Document 7 of 10 — Build Plan for the First Version**
**Version:** 1.0
**Goal:** Define the smallest useful version of the app that can launch, attract real users, and prove the idea.

---

## 1. MVP Goal

Build a simple but powerful platform that helps people connect at the local, state, and national level around shared causes, communities, and awareness.

The MVP should answer one core question:

> Can people join a community, share useful local information, and collaborate around a real purpose easily?

---

## 2. MVP Vision

The first version should focus on:

- community creation and joining
- local awareness and civic updates
- simple messaging
- event creation and participation
- user profiles and trust

The MVP is not about building every feature. It is about proving that community-based connection can create real value.

---

## 3. MVP User Groups

The first version should target 3 core groups first:

1. **Students and teachers**
   - study groups
   - local education awareness
   - campus and city-level communities

2. **Local professionals and citizens**
   - local discussions
   - community problem solving
   - awareness campaigns

3. **Creators and organizers**
   - event promotion
   - awareness content
   - community building

These groups are easier to onboard and can generate early engagement quickly.

---

## 4. MVP Features

### 4.1 Authentication and Profiles
- sign up with email or phone
- basic profile creation
- role selection: student, teacher, professional, organizer, citizen, business
- profile photo and short bio

### 4.2 Communities
- create community
- join community
- community categories: local, state, professional, education, civic, event-based
- community description and rules

### 4.3 Posts and Awareness Content
- create posts in communities
- text posts, image posts
- local updates, awareness posts, civic messages

### 4.4 Events
- create local events
- RSVP to events
- event details with date, time, location, description

### 4.5 Messaging
- direct messages
- community group chat
- simple notifications

### 4.6 Discovery
- discover nearby communities
- discover communities by state, city, and topic
- recommended communities based on interests

### 4.7 Moderation
- report inappropriate content
- basic moderation tools for community owners

## 6. MVP User Flow

### New User Journey
1. User signs up
2. User selects interests and role
3. User sees relevant communities nearby
4. User joins one community
5. User creates or sees a post
6. User joins or creates an event
7. User starts chatting with others

This flow should feel simple and rewarding in the first session.

---

## 7. Recommended First Launch Theme

The best first launch theme is:

### “Clean City and Community Awareness”

Why this is a strong first theme:
- highly relatable across India
- easy for local communities to participate in
- creates strong early engagement
- demonstrates social impact clearly

This theme can later expand into education, jobs, local business growth, and civic development.

---

## 8. MVP Technical Scope

### Frontend
- mobile-first web app or React Native app
- simple, clean UI
- fast loading
- low-data usage friendly

### Backend
- user accounts
- communities
- posts
- events
- messaging
- notifications

### Database
- users
- communities
- community_members
- posts
- events
- event_rsvps
- messages
- notifications

### Recommended stack
- Frontend: React or React Native
- Backend: Node.js with NestJS
- Database: PostgreSQL
- Storage: Cloud storage for images
- Auth: email/phone OTP or social login
- Hosting: Vercel / Render / AWS

---

## 9. MVP Success Criteria

The MVP is successful if:

- users can sign up easily
- users can join a community in under 5 minutes
- users can create a post or event
- users interact with others meaningfully
- at least one local community becomes active within the first 2 weeks

---

## 10. 30-Day Build Plan

### Week 1
- define product scope
- create UI wireframes
- set up authentication
- set up database schema

### Week 2
- build community creation and joining
- build posts and feed
- build event creation

### Week 3
- build messaging and notifications
- build discover and search
- add moderation basics

### Week 4
- test with real users
- fix onboarding issues
- launch initial beta version

---

## 11. Recommended Launch Strategy

### Phase A — Private Beta
- invite 50 to 100 users
- test in one city or one state
- collect feedback

### Phase B — Local Community Launch
- launch with 3 to 5 active communities
- focus on one clear purpose

### Phase C — Regional Expansion
- expand to more states and cities
- add more categories and communities

---

## 12. Final Recommendation

The MVP should be simple, useful, and community-first.

Do not try to build the full national vision in version 1. Build a product that makes people feel:

- connected
- informed
- useful
- part of something bigger

If the MVP works, the larger vision will grow naturally.
