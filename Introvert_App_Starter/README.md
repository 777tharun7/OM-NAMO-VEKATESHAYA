# Introvert App Starter

This is a lightweight starter app for the Project Introvert MVP.

## What is included
- a state-level landing experience for Andhra Pradesh and Telangana
- professional and civic communities for students, teachers, police, lawyers, collectors, government servants, IT employees, PR teams, news reporters, TV channels, and content creators
- nearby-area community cards for local coordination
- state campaigns and events
- a simple growth story section for scaling from state to national level

## Run locally
From this folder, open the index.html file in a browser, or use a simple local server.

If you have Python installed:

```bash
python3 -m http.server 3000
```

Then open http://localhost:3000
